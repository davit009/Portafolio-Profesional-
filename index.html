Implementación de RustDesk para control remoto de dispositivos

Contexto y problema

En la empresa donde trabajo se implementa RustDesk para controlar dispositivos de forma remota. Ya existía otro software de gestión de dispositivos; RustDesk se suma para que lo usen tanto los administradores como otros usuarios con dispositivos de la empresa (móviles y Windows).

Objetivo

  • Configurar perfiles en RustDesk.
  • Asignar dispositivos móviles y Windows a esos perfiles.
  • Administrar todo correctamente desde el perfil de administrador.

Herramientas y tecnologías

  • RustDesk
  • Consola web de RustDesk
  • Dispositivos móviles
  • Windows
