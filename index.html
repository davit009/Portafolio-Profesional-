Proyecto 01

Implementación de RustDesk para control remoto de dispositivos

Implementación de RustDesk en la empresa donde trabajo para controlar de forma remota dispositivos Android y Windows, con perfiles configurados y administrados desde el perfil de administrador.

Rol y responsabilidad

Como estudiante de ingeniería en prácticas profesionales (becario en la empresa), soy el administrador de este proyecto. Mi responsabilidad fue crear cada perfil con los roles que ofrece la aplicación.

Contexto y problema

En la empresa donde trabajo se implementa RustDesk para controlar dispositivos de forma remota. Ya existía otro software de gestión de dispositivos; RustDesk se suma para que lo usen tanto los administradores como otros usuarios con dispositivos de la empresa (Android y Windows).

Objetivo

  • Configurar perfiles en RustDesk.
  • Asignar dispositivos Android y Windows a esos perfiles.
  • Administrar todo correctamente desde el perfil de administrador.

Herramientas y tecnologías

  • RustDesk
  • Consola web de RustDesk
  • Android
  • Windows

Estado actual y resultados

  • Red y conectividad: funcionando; los dispositivos se conectan entre sí.
  • Configuración: quedan algunos puntos por afinar.
