# Portafolio Profesional

Página web estática (HTML, CSS y JS) para el Entregable 3: Portafolio Profesional Digital (FITEC).

## Estructura

- `index.html` — portada, índice de proyectos, detalle de cada proyecto y contacto.
- `styles.css` — estilos (modo claro/oscuro, responsive).
- `script.js` — menú móvil.

Los textos marcados como `[PENDIENTE: ...]` son espacios reservados que faltan por completar.

## Despliegue

Sitio estático sin build; se puede publicar directamente en Vercel.
