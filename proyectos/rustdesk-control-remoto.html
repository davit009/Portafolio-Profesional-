Caso de estudio 03 · Administración de endpoints

Control remoto con RustDesk.

Implementación de RustDesk en la empresa donde realizo mis prácticas profesionales, para controlar de forma remota los dispositivos Android y Windows de la empresa con perfiles y roles administrados desde la consola web.

Organización
Empresa de prácticas profesionales
Rol
Administrador del proyecto · Becario
Periodo
Agosto – diciembre 2026
Estado
En curso

RustDesk · Consola web de RustDesk · Android · Windows

01Contexto y problema

Una herramienta más, bien organizada.

En la empresa ya existía un software de gestión de dispositivos. Se decidió sumar RustDesk para que tanto los administradores como otros usuarios con dispositivos de la empresa (móviles Android y equipos Windows) pudieran controlarlos de forma remota.

El reto era organizar ese acceso: definir perfiles, asignarles los dispositivos correctos y mantener todo bajo control desde un perfil de administrador.

02Rol y responsabilidades

Administrador del proyecto.

Como estudiante de ingeniería en prácticas profesionales (becario en la empresa), soy el administrador de este proyecto. Mi responsabilidad fue crear cada perfil con los roles que ofrece la aplicación.

Objetivos

  • Configurar perfiles en RustDesk.
  • Asignar los dispositivos Android y Windows a esos perfiles.
  • Administrar todo correctamente desde el perfil de administrador.

03Herramientas y tecnologías

Una consola. Dos plataformas.

Plataforma

  • RustDesk
  • Consola web de RustDesk

Dispositivos

  • Android
  • Windows

04Solución

Todo se administra desde la consola web.

Desde el perfil de administrador se crean los perfiles con sus roles y a cada perfil se le asignan los dispositivos que le corresponden.

  1. Perfil de administrador

    Gestiona toda la configuración

  2. Consola web

    Punto central de administración

  3. Perfiles con roles

    Creados con los roles que ofrece la aplicación

  4. Dispositivos

    Android y Windows asignados a cada perfil

Diagrama conceptual de la implementación. RustDesk complementa al software de gestión de dispositivos que ya existía en la empresa.

05Resultados e impacto

La conectividad ya funciona.

  • Red y conectividad funcionando: los dispositivos se conectan entre sí.
  • Configuración: quedan algunos puntos por afinar.

Impacto

RustDesk queda como una herramienta de control remoto complementaria al software de gestión existente, para administradores y usuarios con dispositivos de la empresa.

Próximo paso

Afinar los puntos de configuración pendientes para cerrar la implementación.
